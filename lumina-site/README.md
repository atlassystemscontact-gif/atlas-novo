# Clínica Lúmina — projeto conceitual

Landing page conceitual de uma clínica premium de odontologia, criada para o portfólio da Atlas Systems como exemplo de Landing Page de Performance.

## Visualização local

Abra esta pasta no terminal e execute:

```bash
python3 -m http.server 4174
```

Depois, acesse `http://localhost:3004`.

## Arquivos principais

- `index.html`: estrutura semântica, SEO e conteúdo.
- `styles.css`: identidade visual, responsividade e animações.
- `app.js`: interações, acessibilidade e efeitos suaves.
- `assets/images`: imagens originais geradas para este conceito e otimizadas em WebP.
- `assets/icons`: diretório reservado para ícones do projeto.

## Observação

Este trabalho não representa uma clínica real e não contém promessas, dados clínicos, depoimentos, registros profissionais ou resultados odontológicos. Todos os fluxos de contato são demonstrativos.
